# 探索段階7結果：生データ（canvas JSON）の構造分析

## 概要

canvas JSON の `ax/ay/cw/ch` 値の正確性、Python 推定 vs ブラウザ測定の差、実際のノードサイズを検証した。

---

## 発見1: canvas JSON の children データ構造

### 主人公ノードの children データ
```json
{
  "id": "主人公",
  "x": 1575,
  "y": 250,
  "width": 160,
  "height": 120,
  "children": [
    {"label": "tags", "text": "[[main]], [[human]], [[knight]]", "cw": 160, "ch": 22, "ax": 10, "ay": 8},
    {"label": "ally", "text": "[[騎士団長]], [[幼なじみ]], [[盗賊]]", "cw": 156.9, "ch": 22, "ax": 10, "ay": 30},
    {"label": "rival", "text": "[[四天王A]]", "cw": 60.0, "ch": 22, "ax": 10, "ay": 50},
    ...
  ]
}
```

`cw` / `ch` / `ax` / `ay` が事前計算済みで設定されている。

---

## 発見2: Python 推定 vs ブラウザ測定の差

| テキスト | Python 推定 | ブラウザ測定 | 差 | 誤差率 |
|---------|------------|-------------|-----|--------|
| [[main]], [[human]], [[knight]] | 161.4 | 151.1 | 10.3 | 6.8% |
| [[騎士団長]], [[幼なじみ]], [[盗賊]] | 135.6 | 165.7 | -30.1 | -18.2% |
| [[四天王A]] | 60.0 | 54.6 | 5.4 | 9.9% |
| [[四天王B]] | 60.0 | 55.1 | 4.9 | 8.9% |
| [[幼なじみ]], [[王女]] | 85.2 | 101.3 | -16.1 | -15.9% |
| [[賢者]], [[騎士団長]] | 85.2 | 101.3 | -16.1 | -15.9% |

### 問題
- 日本語テキストでは Python 推定値が実際に描画されるよりも 15-18% 狭い
- canvas JSON の `cw` 値が狭くなり、UI 表示が崩れる可能性がある

---

## 発見3: 実際のノードサイズが型定義と一致している

### 検証結果
| ノード | canvas JSON サイズ | 型定義サイズ | 一致 |
|--------|-------------------|-------------|------|
| 主人公 | 160x120 | 160x120 | ✅ |
| 四天王A | 160x120 | 160x120 | ✅ |
| 四天王B | 160x120 | 160x120 | ✅ |
| 四天王会戦 | 280x160 | 280x160 | ✅ |

**canvas JSON のノードサイズは型定義と完全に一致している。**

---

## 結論

P6（横幅が極端に広い）の原因は **canvas JSON のデータ構造には問題がない** ことが確認された。

問題は **`render()` 内の `n.width/n.height` ミューテート** にある。
canvas JSON の `width=160, height=120` が正しいが、`render()` 内で `n.height = COLLAPSED_HEIGHT (35)` に上書きされることで、サイズ暴走が発生している。

---

## 修正方針（段階 1-6 からの統合）

| 優先度 | 修正内容 | 関連段階 |
|--------|----------|----------|
| **P0** | `render()` 内で `n.width/n.height` をミューテートしない | 段階 1, 2, 6 |
| **P0** | `render()` 最後で `expandedId=null` をリセットしない | 段階 2, 3 |
| **P0** | `applyNodeView()` で `expanded=false` の時、`td.node_width/td.node_height` を使う | 段階 3 |
| **P0** | Path A にアイコン描画コードを追加 | 段階 5 |
| **P1** | character_card 他 5 型に `expandMinW/expandMinH` を追加 | 段階 2.5 |
| **P1** | ToggleExpand のデフォルト anchor を `center/center` に変更 | 段階 5 |
| **P2** | `COLLAPSED_HEIGHT = 35` → `40` に調整 | 段階 2 |
| **P2** | `drawElement()` の条件を緩い比較に変更 | 段階 4 |
| **P2** | `resolvePositions()` の `padX * 2` 二重加算を修正 | 段階 6 |
| **P2** | 各 Nodeview に `collapsedFillOpacity/expandedFillOpacity` を追加 | 段階 2.5 |
